# 席ごとのデモ画面の文言と構成（2026-09-06）

対象は `qomm_demo/static/`（`index.html` / `demo.js` / `demo.css`）と、
`qomm_demo/react-flow/` から生成する React Flow の束です。サーバー（`rust/qomm-demo`）の
API、WebSocket の内容、決済の意味は変えていません。動作の説明は
[../DEMO.md](../DEMO.md) を参照してください。

## 言い回しの決めごと

- 製品名（QOMM、DeFMI、zkPI、Maker、Taker、MP-SPDZ）はそのまま使い、役割は文で
  説明します。席の一覧は「注文を出す側（Taker）」「気配を出す側（Maker）」
  「計算ノード」の順に分け、それぞれ一行で何をする席かを添えます。
- 計算エンジンの札は「試作エンジン（比較は平文）」「秘密計算で価格照合」とし、
  実装名（Rust 試作、MP-SPDZ 実行）は説明文の側に残します。
- 段階の名前は動作で書きます。「注文と気配の方針を分けて配る」「入力が正しいか
  確かめる」「中身を見ずに価格を比べる」「注文者だけが読める結果を返す」
  「証明を確かめて DeFMI で決済」。復旧待ちには「（未成立）」を添えます。
- 「MPCノード」は「計算ノード」、「zkPI証明検証」は「決済の証明（zkPI）」、
  「DeFMI決済台帳」は「DeFMI 台帳」、「状態根」「台帳ハッシュ」は「台帳の識別値」。
- ラウンド番号の横の時間は経過時間なので「処理時間」と呼びます（以前の
  「完了まで」は残り時間に読めました）。
- 図の中の数値は実際の設定から出します。計算ノードの台数は部屋の設定、比較の
  方式はエンジン設定から表示し、固定文字（5 / 7、MP-SPDZ）は使いません。
- 英語表示も同じ方針で対応する語を更新しています（`?lang=en`、EN/JA ボタン）。

## 図の決めごと

- 図の幅は列幅に合わせて自動で縮小します（寸法や列幅が変わるたびに `fitView`）。
- 線の上の説明は文字幅の札にし、隣のカードにかかりません。
- 二列の指標の見出しは短くし（「予約分」）、銘柄名はツールチップに残します。

### 設計の説明と実装の保証の区別（同日、親の指摘後）

- 部屋のエンジンが試作（`engine: sim`）のときは、本文の目立つ位置（ヘッダー直下の帯）に
  「価格の比較は暗号化せず平文で行う」「席ごとの表示の絞り込みは画面上の投影で、秘密計算
  による保証ではない」と出す。秘密計算（MP-SPDZ）のときも、投影と保証の区別を一文で出す。
- 「分割された値だけが渡る」「どの計算ノードにも全体は渡らない」は「設計では」と付けて
  設計の説明として書き、試作エンジンではロビーの説明冒頭・計算ノード席・図の脚注に
  同じ注意を添える。工程名は「価格を比べる（試作：平文で比較）」、価格照合カードは
  「全社の気配を比較（平文）」に変わる。
- 台帳の記録先は断定しない。「設計では Avalanche 上の DeFMI に記録する」とし、実際の
  記録先は配信形態で分ける：ゲートウェイ無し（`serve_demo` 単体）は「プロセス内の試験用
  台帳で、DeFMI への記録ではない」、ゲートウェイ有りは「ゲートウェイ側の構成に従う」。
  判定はページに埋め込まれる `qomm-gateway-port` の有無による。
- 比較で選ばれた気配と実際の約定を分ける。決済状態が `settled` のときだけ「約定相手」
  「約定価格」と呼び、価格条件外で解放・復旧待ち・ダミーのときは「最良気配の候補（未約定）」
  「比較で選ばれた価格（未約定）」と表示する（価格照合カード、注文者の結果、全体表示の見出し）。
- 台帳カードの「決済」欄は状態で変える：同時引き渡し／確保分を解放／保留／変更なし／—。

## 図を主役にした画面（2026-09-12）

説明カードの下に図を置く構成をやめ、図をブラウザ表示領域いっぱいに常時出し、
操作はすべて図の上に重ねる形にした。サーバー（`rust/qomm-demo`）の API、WebSocket の
内容、席ごとの投影、決済の意味は変えていない。

### 構成

- 上部バーは一行：アプリ名、エンジン札、ラウンド番号と処理時間、自動ラウンドの残り、
  「視点」（いまの席、押すと席の一覧）、「操作」（自分の席の引き出し。全体表示では「設定」）、
  「離席」、EN/JA。狭幅ではラウンド番号を隠し、視点の見出し語を省く。
- その下は `#network-graph` が `main` いっぱい（`position:absolute; inset:0`）。ページ自体は
  スクロールしない。Fullscreen API は使わない。
- 図の左上に重ねるもの：段階の帯と説明文（狭幅では現在の段階だけ名前、他は点）、
  エンジンの注意（試作は一文＋「詳しく」で全文、秘密計算は二文そのまま）、最新の通知、
  初見向けの一行の誘導（× で消え、`qomm.guided` に記憶）。
- 図の左下：役割の凡例と、`<details>` にたたんだ注記（試作の注意、資産を持たない、線の意味、
  設計上の記録先、この部屋の記録先）。狭幅では凡例の札も details の中に入る。
- 右側の引き出し（`#drawer`、幅 `clamp(320px,30vw,420px)`）。狭幅（760px 以下）は下からの
  シート（高さは内容次第、最大 62vh）。中身は一度に一つの「面」：
  - 席の一覧（視点ボタン、または席なしのとき）：表示名、全体表示ボタン、役割ごとの席の
    ボタン、「このデモについて」（たたみ）、参加者の札、通知。
  - 席の札：自分の席なら既存の操作パネル（`#panel`）→残高（`#portfolio-strip`）→
    チャット（`#chat-panel`）。他人の席なら「〇〇 が操作中です」と、その席に届く情報は
    その人の画面にだけ送られる旨。空席なら「自動で動いています」＋表示名＋
    「この席で参加する」（着席中は「この席に移る」。サーバーの `claim` は前の席を自動で解放する）。
  - 価格照合の札：公開情報（暗号文、訂正の回数、訂正できる台数、エンジンの計測）と
    最近のラウンド。全体表示のときだけ全社の気配の表。
  - 決済の証明（zkPI）の札：検証の結果（参照値との一致、停止、復旧待ち）と
    「技術的な補足」（zkPI の設計上の役割、設計上の記録先、この部屋の記録先）。
  - DeFMI 台帳の札：自分の席に届いた決済（注文者・値付け・全体表示）か公開の記録
    （状態と台帳の識別値）、記録先の注記、最近のラウンド。
  - 全体表示の「設定」：部屋の設定（間隔、段階の表示時間、自動ラウンド、入力の検査、
    いま1回実行）、各ノードの動作、全参加者の残高。
- 全体表示から席の札を開くと、その席の中身（注文、方針と気配、動作）を
  「全体表示（デモ専用）」の枠で示し、実運用では他の席から見えない旨を毎回添える。
  通常の席から他人の席を開いても中身は出ない（ビューに無いものは描けない）。

### 操作

- 札はクリック／タップ、または Tab で移動して Enter か Space で開く（`role="button"`、
  `aria-expanded`）。Esc か × で閉じ、閉じると選んでいた札にフォーカスが戻る。
- 着席するとその席の引き出きが自動で開き、離席すると席の一覧に戻る。席を替えると新しい席へ。
  自分で閉じた状態は席が変わるまで保つ。
- 机上：引き出しを開くと `#network-graph` の右端を引き出しぶん縮め、図をその幅で
  配置し直して fitView する。狭幅：モデルを幅合わせ・上寄せで置き、下へパンして読む
  （縦積みの全体を一画面に縮めない）。シートを開くと、選んだ札がシートの上の見える帯に
  来るようパンする（ズームは変えない）。
- 図のパン／ズームと引き出しのスクロール／入力は DOM が別なので混ざらない。

### 文言

- 席の中身に関わる語は「注文者」「値付け」「計算ノード」のまま。上部の「視点」は
  席なしのとき「未参加（公開情報のみ）」。
- 「注文の設定」→「注文を入力する」、価格条件は「買う上限の価格」「売る下限の価格」、
  値付けの項目は「基準価格からのずらし幅」「売値と買値の差（スプレッド）」
  「数量が増えたときの上乗せ」。チャットの説明は「上の入力欄と同じ」。
- 常時出す説明を減らした：役割の一行説明は席の札を開いたとき、設計の説明と技術的制約は
  凡例の注記と「技術的な補足」に残す。英語も同じ鍵で対応する語を入れた。

- `qomm_demo/react-flow/`（`package.json`、`package-lock.json`、`tsconfig.json`、
  `vite.config.ts`、`src/main.tsx`、`src/network.css`、`src/assets.d.ts`）を

  狭幅の視点方針（幅合わせ・上寄せ）、選んだ札をシートの上へ寄せる処理、
  束側の見出し・凡例・脚注と `container.style.height` の固定を撤去（すべて `demo.js` 側へ）。
  `render(container, model, options)` の呼び方は同じで、`options` に `compact`、
  `selectedId`、`insetBottom`、`onNodeSelect`、`selectHint` を足した。

  `demo.css` の `height:auto !important` で押さえるだけになる。
